작은미술관 개인정보처리방침

  • 공고일: 2026년 10월 28일
  • 시행일: 2026년 10월 28일
  • 운영자: 이성현 (개인, 이하 "운영자")

운영자는 「개인정보 보호법」 등 관련 법령을 준수하며, 작은미술관 앱(이하 "앱")을 이용하는 분(이하 "이용자")의 개인정보를 다음과 같이 처리합니다.

작은미술관은 보호자(부모)가 사용하는 앱입니다. 아동이 직접 가입하거나 사용하지 않습니다. 앱은 무료이며 광고와 유료 결제가 없고, 이용자의 개인정보를 판매하거나 광고·마케팅에 사용하지 않습니다.

1. 처리하는 개인정보 항목

1-1. 회원 가입·로그인 (필수)

로그인 방법 항목
이메일 인증코드 로그인 이메일 주소
Apple로 로그인 Apple이 제공하는 사용자 식별값, 이메일 주소(이용자가 "이메일 가리기"를 선택하면 Apple이 생성한 중계 주소)
공통 회원 식별번호(무작위 생성), 가입·최근 로그인 일시, 이용약관·개인정보 처리·자녀 정보 처리 동의 일시
  • 비밀번호는 사용하지 않습니다. 이메일로 받은 일회용 인증코드로 로그인합니다.
  • Apple로 로그인 시 이름은 요청하지 않으며 저장하지 않습니다.

1-2. 자녀 정보 (보호자가 직접 입력)

구분 항목
필수 이름 또는 별명(1~20자)
선택 출생연도, 출생월, 구분 색

성별, 생년월일의 '일', 기관(어린이집·유치원 등) 이름, 주소는 수집하지 않습니다. 실명 대신 별명을 사용해도 됩니다.

1-3. 작품 정보 (보호자가 직접 입력)

  • 작품 사진(원본, 편집본, 목록용 축소본)과 사진 크기, 편집 값(회전·자르기)
  • 작품 제목, 제작일, 작품 이야기(아이가 한 말 등)
  • 작품집 구성 정보(제목, 부제, 선택한 작품과 순서, 표지, 디자인)

작품 사진의 촬영 위치(GPS) 정보는 저장하지 않습니다. 앨범에서 사진을 고를 때 촬영 날짜만 읽어 제작일 기본값으로 사용합니다.

1-4. 서비스 이용 과정에서 자동으로 생성되는 정보

  • 업로드 성공·실패, 작품집 PDF 생성 여부와 같은 서비스 운영 기록(작품 제목·이야기·사진은 포함하지 않음)
  • 서버 접속 기록(접속 일시, IP 주소) — 클라우드 서비스 제공자의 보안·운영 목적 로그

앱은 광고 식별자(IDFA)를 수집하지 않으며, 쿠키나 행태정보 수집 도구를 사용하지 않습니다.

1-5. 기기 권한

권한 용도 필수 여부
카메라 작품 촬영·스캔 선택 (허용하지 않아도 앨범에서 등록 가능)
사진 앨범에서 작품 사진 선택 선택 (허용하지 않아도 촬영으로 등록 가능)

권한은 iPhone 설정 앱에서 언제든 변경할 수 있습니다.

2. 처리 목적

목적 항목
회원 식별, 로그인, 부정 이용 방지 1-1
자녀별 작품 분류, 제작 당시 나이 표시 1-2
작품 보관·감상, 작품집(PDF) 생성 1-3
오류 대응, 서비스 안정성 개선, 이용 통계(개인 식별 불가 형태) 1-4
문의 응대, 중요 공지 이메일 주소

목적이 바뀌는 경우 사전에 알리고 필요한 동의를 받습니다.

3. 보유 및 이용 기간

항목 보유 기간
회원 정보, 자녀 정보, 작품 사진·기록, 작품집 구성 회원 탈퇴 시까지 (자녀·작품·작품집을 직접 삭제하면 즉시 삭제)
서비스 운영 기록(1-4) 생성일로부터 1년. 탈퇴 시 회원 식별번호와의 연결을 즉시 제거
서버 접속 기록 클라우드 서비스 제공자의 보관 정책에 따름

작품집 PDF 파일은 이용자의 기기에서 만들어지며 서버에 저장하지 않습니다.

4. 개인정보의 파기

  • 회원 탈퇴: 앱 > 설정 > 회원 탈퇴를 실행하면 서버의 작품 사진 파일을 모두 삭제한 뒤 회원 정보와 자녀·작품·작품집 정보를 즉시 삭제합니다. 삭제된 정보는 복구할 수 없습니다.
  • 개별 삭제: 작품·자녀·작품집을 삭제하면 관련 데이터와 사진 파일을 즉시 삭제합니다.
  • 전자 파일은 복구할 수 없는 방법으로 삭제합니다.
  • 클라우드 서비스의 백업본은 해당 서비스의 백업 주기에 따라 순차적으로 삭제됩니다.

5. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외로 합니다.

원활한 서비스 제공을 위해 다음과 같이 처리를 위탁합니다.

수탁자 위탁 업무 보관·처리 위치

Resend, Inc. 로그인 인증코드 이메일 발송 미국

7. 만 14세 미만 아동의 개인정보

  • 회원 가입은 만 14세 이상만 할 수 있습니다.
  • 앱에 등록되는 자녀 정보(별명, 출생연월, 작품 사진·이야기)는 법정대리인인 보호자가 직접 입력합니다. 가입 시 "자녀 정보 처리 동의(법정대리인)"를 별도로 받으며, 동의하지 않으면 자녀를 등록할 수 없습니다.
  • 자녀 정보는 보호자 계정 안에서만 비공개로 보관되며, 다른 이용자나 외부에 공개되지 않습니다.

8. 정보주체와 법정대리인의 권리와 행사 방법

이용자(및 자녀의 법정대리인인 보호자)는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람·정정: 앱에서 자녀·작품 정보를 직접 조회·수정
  • 삭제: 앱에서 자녀·작품·작품집 삭제, 설정 > 회원 탈퇴
  • 처리정지·동의 철회: 회원 탈퇴 또는 아래 문의처로 요청

문의처로 요청하면 지체 없이(10일 이내) 조치하고 결과를 알려 드립니다.

9. 안전성 확보 조치

  • 모든 통신 구간 암호화(HTTPS)
  • 데이터베이스 행 단위 접근 통제(본인 데이터만 조회·변경 가능)
  • 사진 저장소 비공개 설정, 본인 확인 후 1시간 동안만 유효한 임시 주소로 조회
  • 관리자 권한 키는 서버에만 보관하고 앱에 포함하지 않음
  • 로그인 세션은 기기 내 앱 전용 저장 공간에 보관
